# Context Field Sheet Template
[**Arches for JU Excavations**](https://github.com/mn-lab-platform/arches-for-ju-excavations), together with its Resource Models, has been designed to reflect the excavation recording methodology used by the Jagiellonian University archaeological teams working in Paphos since 2011 within the framework of the **Paphos Agora Project**.

The system follows the principles of **Single Context Recording (SCR)**, a stratigraphic recording method in which each archaeological context is documented as a separate entity and serves as the fundamental unit of archaeological recording. The structure of the data models, terminology, and relationships implemented in Arches have therefore been developed to correspond with this fieldwork methodology.
