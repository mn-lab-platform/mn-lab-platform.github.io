# AfS for Mare Nostrum Lab

This project is MN Lab's adaptation of Arches for Science (AfS) for archaeological excavation work and related digital documentation.

## MN Lab changes

The MN Lab implementation adds and customises:

- Docker, Nginx, and production-deployment configuration for the MN Lab environment;
- a customised landing page and resource-report presentation;
- 3D, IIIF, and RTI viewers for digital resources;
- map and geospatial components for excavation data; and
- integrations and workflows supporting MN Lab's collection, import, export, and visualisation needs.

## Upstream and licence

The deployment is maintained in the [AFS for MN Lab Excavation repository](https://github.com/mn-lab-platform/afs-for-mn-lab). It is a fork of [OpenContext's `arches-via-docker`](https://github.com/opencontext/arches-via-docker).

MN Lab retains the upstream source history and AGPL-3.0 licence. The technical deployment instructions remain in the fork's README; this section documents MN Lab-specific changes.
